# @autoengineering/persistence-sqlite

A local SQLite persistence library with schema versioning support.

## Features

- ES modules (ESM) support
- TypeScript strict mode
- Lazy database initialization
- Schema versioning with migration runner
- Designed for local/Node.js environments (not Cloudflare Workers)

## Installation

```bash
npm install @autoengineering/persistence-sqlite
```

## Usage

See source for API documentation.

## Development

```bash
npm install
npm run build
npm test
```
